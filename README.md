# Apache Airflow Learning

This repository contains my hands-on practice and notes while learning **Apache Airflow** through Apache Airflow offical websites. It includes example DAGs and implementations of core Airflow concepts.

## Topics Covered

- DAG Basics
- TaskFlow API
- Operators
- XComs
- Branching
- Parallel Tasks
- Scheduling
  - Cron Expressions
  - Presets
  - Delta Schedules
  - Interval Schedules
- Special Dates
- Assets
- Asset Dependencies
- DAG Orchestration

## Tech Stack

- Apache Airflow 3.x
- Python
- Docker
